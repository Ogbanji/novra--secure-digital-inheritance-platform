INFORMATION FLOWS:

1. User Registration Flow
   ┌─────────┐       ┌──────────────┐       ┌────────────┐
   │ Browser │──────►│   Backend    │──────►│  SQLite DB │
   │ (React) │  POST │  (Express)   │ Store │  (users)   │
   │         │ /reg  │              │       │            │
   └─────────┘       │ ✓ Hash pwd   │       └────────────┘
                     │ ✓ Gen salt   │
                     │ ✓ Gen JWT    │
                     └──────────────┘
                            │
                            └──────────────► Return token

2. File Upload Flow
   ┌──────────────────────────────────────┐
   │ Frontend (React)                     │
   │ • User selects file                  │
   │ • Generate random nonce              │
   │ • Derive key from password (PBKDF2)  │
   │ • AES-256 encrypt file               │
   │ • Generate auth tag                  │
   └──────────────────────────────────────┘
              │ POST /api/vault/upload
              │ {encrypted_blob, nonce, authTag}
              ▼
   ┌──────────────────────────────────────┐
   │ Backend (Express)                    │
   │ • Verify JWT token                   │
   │ • Extract user_id from token         │
   │ • Check storage limit                │
   │ • Store encrypted blob in DB         │
   │ • Update storage usage               │
   └──────────────────────────────────────┘
              │ Success response
              ▼
   ┌──────────────────────────────────────┐
   │ Frontend (React)                     │
   │ • Update vault state                 │
   │ • Show file in list                  │
   │ • Clear password from memory         │
   └──────────────────────────────────────┘

3. Inheritance Trigger Flow (Dead-Man Switch)
   ┌──────────────────────────────────────┐
   │ Cron Job (Every Hour)                │
   │ • Query all dead-man-switch rules    │
   │ • For each rule:                     │
   │   - Check user.last_activity         │
   │   - Compare against inactivity_days  │
   │   - If exceeded → trigger_rule()     │
   └──────────────────────────────────────┘
              │ Rule Triggered
              ▼
   ┌──────────────────────────────────────┐
   │ Backend                              │
   │ • Generate temporary decryption key  │
   │ • Create inheritance access record   │
   │ • Send email to heir with link/key   │
   │ • Update rule status to "triggered"  │
   └──────────────────────────────────────┘
              │ Email notification
              ▼
   ┌──────────────────────────────────────┐
   │ Heir Email                           │
   │ • "Your inheritance is ready"        │
   │ • Click to claim with temp key       │
   │ • Access expires in 30 days          │
   └──────────────────────────────────────┘

4. Heir File Retrieval Flow
   ┌──────────────────────────────────────┐
   │ Heir                                 │
   │ • Click link in email                │
   │ • Verify identity (security Q)       │
   │ • Receive temp decryption key        │
   └──────────────────────────────────────┘
              │ Request vault item
              ▼
   ┌──────────────────────────────────────┐
   │ Backend                              │
   │ • Verify temp key is valid           │
   │ • Check key hasn't expired           │
